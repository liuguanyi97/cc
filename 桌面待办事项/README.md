# 桌面待办事项

一个 Windows 原生桌面待办 / 每日计划小工具（C# WinForms，红蓝白三色主题），数据存本地文件。

## 功能

- **待办事项**：输入事项回车或点「添加」；点圆圈勾选完成即划掉。
- **每日计划**：按日期记录，顶部日期栏切换任意一天查看历史记录。
- **总结**：每项点「总结」可写总结，随当日记录一起保存。
- **计时**：每项「计时 / 停止」，记录完成该项所用的时间；勾选完成时自动停止计时。
- **本地存储**：数据保存在 `%AppData%\桌面待办事项\data.json`（独立 JSON 文件，不依赖浏览器）。
- **可拖动 / 可缩放**：拖动蓝色标题栏移动窗口，拖窗口四边或四角调节大小。
- **记忆功能**：窗口位置、大小、每日数据都会记住。

## 运行

1. 双击桌面的「桌面待办事项」快捷方式；或直接运行 `app\DesktopTodo.exe`。
2. 需要 .NET 9 桌面运行时（本机已安装）。

## 从源码编译

```
dotnet publish -c Release -o app
```

## 文件

- `Program.cs` / `MainForm.cs` — 源码
- `TodoApp.csproj` — 项目文件
- `app/` — 编译输出（含 `DesktopTodo.exe`）
- `index.html` — 早期网页版（数据存浏览器缓存，非本地文件，现已不用）
